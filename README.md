# Hundappen

PWA för hundägande familjer: logga rastning och mat, dela schema och få pushnotiser.

- Frontend: React + Vite + TypeScript, publiceras på GitHub Pages
- Backend: Supabase

Se [docs/PLAN.md](docs/PLAN.md) för plan och datamodell.

## Utveckling

```sh
npm install
npm run dev
```

Appikoner genereras från `scripts/icon.svg` med `node scripts/make-icons.cjs`.
